# Karibu

Karibu is a modern Visitor Management System built with Next.js, Prisma, and TailwindCSS.

Karibu enables institutions and organizations to:

- Invite visitors
- Manage check-in and check-out
- Track live active visits
- Handle overstay escalation
- Monitor security-controlled exits
- Generate real-time administrative insights

---

## 🚀 Getting Started

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

---

## 🏗️ Tech Stack

- Next.js (App Router)
- Prisma ORM
- SQLite (configurable)
- TailwindCSS
- TypeScript

---

## 🔐 Authentication

Karibu uses secure HTTP-only session cookies for authentication.

Roles supported:

- Admin
- Security
- Host

---

## 📦 Project Structure

- `src/app` – Application routes
- `src/components` – Reusable UI components
- `src/lib` – Utilities (auth, database)
- `prisma` – Database schema and seed
